# Git Island principles

1. **Quiet until useful.** No live PRs means no island. Status should be clear
   without interrupting the work happening underneath it.
2. **Native to the Mac.** Fit the physical notch, preserve the menu bar, and
   respect Reduce Motion and standard macOS behavior.
3. **Attached and predictable.** The island never detaches from the screen top.
   Hovering between groups changes the visible content without jumping the host.
4. **GitHub is the source of truth.** Show actionable states honestly. Never
   imply that a display filter changes the account’s authorization.
5. **Writes are deliberate.** Merging, updating branches, and bypassing protection
   require intentional user action and GitHub’s authorization.
6. **Explain data leaving the Mac.** Document GitHub and optional service traffic,
   credentials, retention, and how access is revoked. No hidden telemetry.
7. **Useful independently.** Periodic GitHub refresh remains usable without
   enrolling in the hosted live-update service.
8. **Open to improve.** Publish original code under GPLv3, keep contributions
   focused, and make compilation and ordinary tests independent of owner secrets.
